02 / Method

Three passes. One evidence trail.

Every claim is traceable to an HTTP-checked docs URL and a logged verification pass.

@COMPOSIO/CORE · ZOD · VITEST
1

Research agent

Concurrency-limited fetcher (p-limit) scrapes official docs, queries Composio's catalog, and extracts strict Zod JSON with append-only JSONL checkpoints (data/checkpoints.jsonl).

DISCOVER · EXTRACT · CHECKPOINT
2

Automated verifier + fixer

Re-fetches every evidence URL across all 100 apps for HTTP 200 + field keyword grounding. Failures trigger a bounded repair loop (max 2 rounds); all diffs log to data/diff-log.json.

FETCH · GROUND · BOUNDED REPAIR
3

Human audit

Deterministic 20-app stratified audit (2 per category) against live docs. Resolved JS-rendered portals and borderline partner gates, then recycled fixes back through Pass 2.

20-APP SAMPLE · FIX · RE-VERIFY

05 / Integrity & Reproducibility

What this page claims & how to run it

Evidence standard & honest limits

Official developer docs are preferred over marketing pages. Self-serve vs paid judgments are based on public docs/pricing text rather than creating 100 paid accounts. JS-rendered portals (Stoplight/Redoc) that could not be text-grounded are honestly downgraded or manually checked in Pass 3.

Run the research agent (3 commands)

Zero hardcoded paths; 25 offline Vitest unit & integration tests pass in under 1 second.

cd backend && npm install
cp .env.example .env
npm run research && npm run verify && npm run build && npm test
