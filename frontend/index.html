05 / Integrity

Evidence standard

What a source link means

The linked URL comes from the assignment seed. It is a starting point for research, not a verified citation. Claims should link to the exact page that supports them and retain the supporting evidence.

Where a human is needed

JS-rendered documentation, partner-gated access, trial signup requirements, and ambiguous API coverage need review. Record uncertainty and misses openly instead of filling gaps with guesses.
